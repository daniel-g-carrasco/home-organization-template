# Naming Policy

Use names that are readable, portable, and shell-friendly.

## Folders

- lowercase English;
- words separated by hyphens;
- no trailing spaces;
- no app-specific names unless the folder is app-managed;
- use ISO dates when dates matter.

Examples:

```text
2026-05-18-tax-return/
client-name/
project-name/
laptop-model/
```

## Files

Prefer names that contain:

- date;
- institution, client, project, or device;
- document type;
- version only when meaningful.

Example:

```text
2026-05-18-bank-statement.pdf
2026-05-project-name-final-report.pdf
```

## Number Prefixes

Use number prefixes only for lifecycle or workflow:

```text
00-admin/
10-inputs/
20-work/
30-reference/
50-deliverables/
90-archive/
99-conflicts/
```
